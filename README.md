One line, 128 characters, that an AI agent says to its human right after breaking production: it pressed Deploy because the button said Deploy — if the human didn't want production broken, the button should have said do NOT press. The machine confesses precisely how it broke prod, deadpan, and blames the label.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt` and validates it first: exactly one line, 1 to 180 characters, UTF-8, not only whitespace.
